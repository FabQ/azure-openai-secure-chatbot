# Azure OpenAI Secure Chatbot

This repository contains small, production-focused AI chatbot components using Azure OpenAI and Flask, built incrementally.

## 🧭 Structure


## 🔧 Requirements
- Python 3.10+
- Azure Subscription
- Terraform (if using infra modules)

## 📖 Feature Overview

| Folder             | Description                                         |
|--------------------|-----------------------------------------------------|
| baseline-chatbot/  | Simple chatbot with Flask + GPT-4o (no auth)        |
| entra-auth/        | Same chatbot secured with Entra ID (WIP)            |

Each folder contains its own README with setup instructions and link to corresponding blog post.
